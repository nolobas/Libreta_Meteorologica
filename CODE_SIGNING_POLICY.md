# Política de firma de código

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

## Qué se firma

Solo se firman los archivos para Windows compilados automáticamente por GitHub Actions a partir del código fuente público de este repositorio:

- `LibretaMeteorologica.exe` (el programa)
- `LibretaMeteorologica-…-Instalador.exe` (el instalador)

No se firman archivos compilados en computadoras personales.

## Equipo

| Rol | Personas |
|---|---|
| Autores (committers) y revisores | Colaboradores del repositorio |
| Aprobadores de cada firma | Propietarios del repositorio |

Todos los integrantes usan verificación en dos pasos en GitHub y en SignPath.

## Privacidad

Este programa no transfiere información a ningún otro sistema conectado a una red. Todos los datos se guardan localmente en la computadora del usuario.
